# Оно тебе надо

Учебный проект Яндекс Практикума — страница аукциона вещей, в которые никто не верил.

## Репозиторий

https://github.com/rifdedking-code/ono-tebe-nado

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Технологии

HTML5, CSS, Grid и Flexbox, методология БЭМ. Шрифты Raleway и изображения подключены локально относительными путями.

## Секции

- Шапка с навигацией и контактами.
- Обложка с заголовком и кнопкой ставки.
- Карточки трёх лотов.
- Информация об аукционе.
- Подвал с контактами и ссылками на социальные сети.

Страница рассчитана на ширину 1100 пикселей по условиям проекта. Отправка ставки и загрузка дополнительных лотов не реализуются в рамках статической вёрстки.
